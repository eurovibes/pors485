# pors485 - A Power over RS485 board

To pass electric power along with data on shared line is a common requirement.
The Power over RS485 board provides a solution to fit these needs. The board
can both inject and receive power from the bus. It is designed to operate with
Voltages from 7V to 36V up to a current of 4A.
